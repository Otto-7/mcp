SAST — анализ исходного кода без запуска. Ищет уязвимости и ошибки по таким признакам как: паттерн, структура, поток данных.
```mermaid
mindmap
  root((SAST))
    Pattern-based
      Поиск опасных паттернов
      Пример: memcmp с char
    Data-flow
      Анализ значений переменных
      Пример: x > int.MaxValue
    Taint
      Путь данных от источника к приёмнику
      Пример: SQL-инъекция
```
