MCP-сервер для автоматизированной обработки результатов статического анализа программного обеспечения.
## О проекте
Цель - разработать программный прототип MCP-сервера для загрузки, нормализации и аналитической обработки результатов SAST с последующим предоставлением этих данных большой языковой модели; изучить архитектуру систем на основе протокола MCP.
